# My Radio Player
A simple web page for listening to Croatian internet radio stations.

## Features
- List of stations
- Click to play
- Works on phone and desktop

## How to use
1. Open the page
2. Click a station

## Live demo
[Open the site](https://korisnik700.github.io/)

## Adding a station
Edit the `stations` list in `index.html`:

    { name: "Station name", url: "https://example.com/stream.mp3" }
